# 微光小鎮 3D 實驗線（GlimmerTown3D-lab）

**同一座城、三種時間。**

- **建造**：你親手蓋出一座城。
- **一生**：一個市民在這座城裡活完一輩子，城市在他身邊長大。
- **考古**：數百年後，城市已經荒廢；你走進廢墟，讀出它的歷史。

三種玩法共用同一個 3D 世界，和同一份「世界歷史」。

《微光小鎮 Glimmerville》的第三條線。另外兩條是 2D：主線 [GlimmerTown](https://github.com/lijiabao1998/GlimmerTown)，以及美術實驗線 [GlimmerTown-lab](https://github.com/lijiabao1998/GlimmerTown-lab)。

- 願景與里程碑：[`docs/D000-vision.md`](docs/D000-vision.md)
- 給 Claude 的常駐規則：[`CLAUDE.md`](CLAUDE.md)
- 每一輪做了什麼、沒做成什麼：[`LOG.md`](LOG.md)

## 目前狀態：D022 糧食——供糧率與每棟住宅每天的糧食加減（接在 D021、D020 之後）

業主 2026-09-25 定案：只參考 2D 實驗線、全力做建造、原始碼零外部素材、本倉庫定位是 Pre（看 [`docs/D003-lab-city-import.md`](docs/D003-lab-city-import.md)）。

**線上版**：<https://lijiabao1998.github.io/GlimmerTown3D-lab/>。手機可以直接開。

- 第一次打開是一座**新城**：種子城的地形、手上 $3000、第 1 天、暫停。
  - 選「路」（五級可選），一指按住拖出一條路，放開才蓋；拖的時候每一格會標出能不能蓋、總價多少。
  - 選「住／商／工」拖出一塊分區；「電」點一下蓋電廠；「拆」一次拆一層；↩ 復原今天的施工，全額退錢。
  - 「公共設施」一組（D016）有十三種：公園、水塔、配水管、消防局、警察局、派出所、醫院、診所、學校、圖書館、郵局、墓園、垃圾場；點一下蓋（公園用框，配水管用拉線）。
  - 按 ▶，城市照實驗線的規則自己長，每天收稅、付維護費；人口到門檻有里程碑獎金，星等升級有獎金。
  - 關掉再開，城還在：目前的城存成實驗線的分享碼，世界歷史一筆一列存在瀏覽器的 IndexedDB（只增不改，D013）。☰ 選單可以匯出分享碼，貼進 2D 實驗線就能開。
- 兩指縮放、平移；沒選工具時一指轉鏡頭。點建築看它是什麼、哪一天蓋的、之後發生什麼事。

- ☰ 選單裡還有實驗線樣張頁的**種子城**、**AI 城 120 天**、全種類樣張，也可以**貼上自己在 2D 實驗線匯出的分享碼**（這些城只能看）。
- 3D 讀的是實驗線存檔裡的每一格和每一棟：地形、高地、水、道路、鐵路、分區、樹，以及 186 種建築的種類、等級、佔地。
- D004–D008 已做住商工街區配方、地面與明暗、183 種非住商工建築造型，以及英美立面的逐戶細節。D012 起預設 C 檔（超街區補滿），B 檔照 2D 實驗線切分街區，☰ 選單可以切換；A 檔（D004 的密度對照）D014 起拿出選單，`?blocks=a` 還開得到。
- [D009](docs/D009-growth-formulas.md) 把生長、升級、幸福、地價、天氣與舊式供電等核心公式搬到純邏輯模組，與 2D 實驗線原始碼逐項對拍。
- [D010](docs/D010-starter-city.md) 把這些公式照實驗線 `tick()` 的順序接成逐日模擬：選單的**起步城**（路、住商工分區、一座電廠、一間警局）按 ▶ 就會自己長，每一棟長出來、每一次升級都記進世界歷史。
  - 跟實驗線從同一個起點各跑 8 個種子 × 120 天：第 1 天逐項相等，第 2 天起分岔。
  - 分岔是因為實驗線還有經濟、通勤、垃圾、糧食、疾病等系統，本線還沒搬；差多少、為什麼，列在卡上。
- [D011](docs/D011-build-mvp.md) 是第一個能玩的循環：玩家自己鋪路、劃區、蓋電廠和警察局、拆除、復原，每天結算。
  - 規則、數字、資料格式都照實驗線：放置規則與每日結算把實驗線原始碼放進 Node 跑，256 張隨機小圖 9,659 筆操作、2,700 組結算逐項相等；本線改一個數字、實驗線改一個數字都會被抓到。
  - 同一串操作在實驗線頁面上實跑（它自己的拉線、框選、復原函式）：8 個種子共 312 筆操作之後的資金、格子、各種場逐位相等；兩邊互相匯出的分享碼讀回來都一樣。
  - 第 2 天起兩邊還是會分岔，原因跟 D010 一樣：實驗線的經濟、垃圾、通勤等系統本線還沒搬。
  - 按鈕、手勢、畫面是本線自己設計的（業主：UI 可以更現代）。

- [D014](docs/D014-construction-and-detail.md) 讓房子不再突然冒出來：照實驗線 T259 的 9 天工期。
  - 第 0 天開挖（圍籬、深坑、挖掘機、傾卸車），第 1 天打地基（鋼筋、攪拌車），第 2–3 天鋼骨框架長高、塔吊上場。
  - 第 4–8 天樓體一層一層長高，實驗線的露出比例 30／50／68／84／96%，外面搭鷹架、塔吊吊料到當下的樓板。
  - 1 倍速下每一幀都在長；塔吊、挖掘機、攪拌車、工人只在播放時動。住商工自然升級時照實驗線重蓋一次。
  - 近看有細節：牆面照屋齡風化（T591，14／120／240 天三級），拉近還有牆腳的花台、垃圾桶、冷氣機、工安斜紋、棧板、立管（T599）。
  - 地面改成只重畫變動的格。
- [D015](docs/D015-incremental-rebuild.md) 讓城市長大時的場景重建變輕：畫面一個像素都不變。
  - 每個街區、每棟建築的幾何照「件」快取，只重畫變了的（起步城每次重建約一成）。
  - 建築的頂點緩衝、地面貼圖常駐在 GPU，只上傳改到的那幾段：起步城一次重建從約 2.3 MB 降到約 190 KB。
  - 手機代理（CPU 降速 6 倍）下一次重建的主執行緒時間約少了六成；施工、拆除、復原之後的重建也一樣變輕。
- [D016](docs/D016-civic-tools.md) 是第二批建造工具：公共設施九種（公園、消防局、派出所、醫院、診所、學校、圖書館、郵局、墓園），加上原本的警察局，放在同一組按鈕裡。
  - 放置規則、造價、覆蓋半徑、每天的維護費與固定就業都照實驗線：實驗線原始碼在 Node 跑 164 張隨機小圖 6,297 筆操作，逐筆相等。
  - 同一串操作在實驗線頁面上實跑 8 個種子：每一筆、第 1 天的結算、旁邊住宅的幸福、兩邊互相匯出的分享碼，都一樣。
  - 這批設施目前透過覆蓋範圍影響幸福、地價與評分；火災、犯罪、疾病這些系統還沒搬，所以消防局還不會救火。
- [D017](docs/D017-noise.md) 把實驗線的噪音搬過來：機場、體育場、車站、焚化廠、物流中心、貨櫃碼頭等 19 種建築會吵到附近的住宅（幸福）和地價。
  - 本線自己還蓋不出噪音源，這一張主要修的是**讀進來的城**：從實驗線貼過來的分享碼、樣本城。
  - 噪音場跟實驗線原始碼逐格相等；實驗線頁面上留著體育場實跑 8 個種子，住在噪音裡的那一棟住宅幸福也逐位相等。
- [D018](docs/D018-park-art.md) 讓公園不再長得一樣：照實驗線公園精靈的九種設計畫——石徑長椅花、石徑、池塘、噴泉廣場、玫瑰園、遊樂場、涼亭、球場、野餐區。
  - 蓋公園時照實驗線抽一個變體；顏色逐色取實驗線原文，地坪改成實驗線的草地。
  - 公園以外的 182 種建築逐位不變（動手前錄了全種類的幾何雜湊表）；一座公園最多 182 個三角形。
- [D013](docs/D013-indexeddb-history.md) 把世界歷史從存檔裡搬到瀏覽器的 IndexedDB：一筆一列、只增不改。
  - 之前歷史跟著存檔塞在 localStorage，約 8 萬筆就存不下，而且每一筆手勢都要把整份歷史重寫一次。現在每一次只附加新的那幾列，9 萬筆跟 1 萬筆存一次一樣快。
  - localStorage 照舊放實驗線格式的目前狀態，貼進實驗線照樣能開；舊存檔照讀，存一次就搬進日誌；匯出的分享碼照舊帶整份歷史。
  - 瀏覽器不給用 IndexedDB 時，退回舊的存法，狀態列亮「⚠ 歷史有上限」。
- [D019](docs/D019-water.md) 是城市系統的第一張：供水。
  - 「公共設施」一組多了水塔（$400）和配水管（拉線，$10／格）。水塔旁邊接上水管，水管兩格內有電的住商工就有水；一座水塔供 80 棟。二級要有水才升得到三級。
  - 規則照實驗線的舊式供水網逐行搬：實驗線原始碼在 Node 跑 360 張隨機小圖逐格相等；實驗線頁面上 8 個種子拉水管、推進一天，每一棟有沒有水都一樣；讀進來的 AI 城 120 天也一樣（60／314 棟有水）。
  - 水管跟實驗線一樣平常埋在地下，拿著水塔或配水管才畫出來。建築卡講這一棟有沒有電、有沒有水。
  - 人口 500 以上二級升三級還要污水接管，污水還沒搬，所以大一點的城有水也還長不出三級；摩天樓合併也還沒搬。
- [D020](docs/D020-garbage.md) 是城市系統的第二張：垃圾。
  - 「公共設施」一組多了垃圾場（$300，處理 40）。沒有垃圾場、容量不夠、離垃圾場沿路超過 18 格，住宅都會不開心；人口 500 以上只算貼路的處理設施，路網分成清運區，各區自己的容量自己用。城市評分的垃圾那一項也照這個算。
  - 規則照實驗線的清運網與清運區原文搬：實驗線原始碼在 Node 跑 420 張隨機小圖逐格相等；實驗線頁面上 8 個種子蓋垃圾場、推進一天，每一棟住宅的幸福逐位相等（只差糧食那一項）；讀進來的 AI 城 120 天、種子城，把實驗線那一天的輸入代進本線的垃圾那一段，每一棟也逐位相等（種子城本線的人口少算了住宅塔、巨廈，自己推進會不同，列在卡上）。
  - 起步城跟實驗線的差距因此小了一截：第 120 天城市幸福本線 0.234、實驗線 0.236（D019 時本線 0.400）。（這個「幾乎相等」是巧合，D022 查清楚了：見下。）
  - 建築卡多一列「清運」：全城垃圾與容量、垃圾場沿路幾格、有沒有扣分。
- [D021](docs/D021-read-in-population.md) 補上讀進來的城的人口：
  - 住宅塔、巨廈的居民不看有沒有電，算進人口（種子城本線人口從 0 變成 1,400，跟實驗線一樣）；讀檔之後、第一天之前的人口也照實驗線算（種子城 5,436）。人口 500 以上才走正式清運、垃圾量看人口，所以這一筆會改變讀進來的城的垃圾數字。
  - 45 座城（預建城、AI 城、種子城、全種類樣張城、自己造的 34 座）讀檔後與推進一天後的人口，在實驗線頁面上逐座相等；把補丁拿掉六種不同的做法，守衛都會紅。
- [D022](docs/D022-food.md) 是城市系統的第三張：糧食。
  - 每天算食物量（農場、大農場、牧場、溫室、釣魚碼頭、社區菜園、魚塘；農場看季節）、遊客（觀光建築、地標、會展中心每 20 天一波）、貿易額度（路格、貿易站、港口、貨運、倉儲），居民每 10 人、遊客每 160 人要 1 單位糧食，本地不夠向貿易額度拿；供糧率 −.5 再乘 .11（夾在 −.06～.05）就是每棟住宅每天的幸福加減。起步城沒有農場、額度只有 3，所以人口一多，每棟住宅每天扣約 .045。
  - 規則照實驗線原文搬：實驗線原始碼在 Node 跑 700 張隨機小圖、每張三天，每個計數與數字逐位相等（實驗線原文改 26 處、本線改 38 處，全都轉紅）；實驗線頁面上 80 座城推進一天，判的 75 座、1,323 棟住宅，糧食那一段的每個輸入輸出與每一棟住宅的幸福全部相等；D011、D016、D017、D019、D020 的預建城對拍不再需要「套糧食」，直接相等。
  - 實驗線有、本線沒搬的輸入（物流、化肥、船、火車線、壅堵、城市活動、政策、污水廠）會讓讀進來的城不一樣：AI 城的政策「公園夜間開放」每棟 +.02、種子城進口 4／42，卡上都記了，只量不判。
  - 住宅的建築卡多一列「糧食」。
  - 起步城第 121 天的幸福 0.234 → 0.192 不是變差：D020 那時的 0.234 剛好是「沒糧食的扣分」抵掉「本線 6 成住宅沒電」的巧合。糧食單日算式跟實驗線逐位相等，前 60 天的差縮小（46–60 天 .032 → .004）；後段拉開的來源是本線的城長到 146 棟（實驗線 54 棟）、超過發電廠容量，那由需求決定，等經濟快照與通勤。

## 本機開發

```bash
npm install
npm run dev        # 開發伺服器 http://localhost:8301
npm run build      # 輸出單一 dist/index.html
npm run unit       # Node 端守衛：解碼、內容對拍、D009 公式與供電實跑、D010 場對拍與逐日模擬、D011 建造與資金對拍、施工整合、實驗線實跑錨點、D014 施工分期與近看細節、D015 件的鍵夠不夠、D016 公共設施對拍、純度、零外部素材
```
