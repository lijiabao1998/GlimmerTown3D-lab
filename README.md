# 微光小鎮 3D 實驗線（GlimmerTown3D-lab）

**同一座城、三種時間。**

- **建造**：你親手蓋出一座城。
- **一生**：一個市民在這座城裡活完一輩子，城市在他身邊長大。
- **考古**：數百年後，城市已經荒廢；你走進廢墟，讀出它的歷史。

三種玩法共用同一個 3D 世界，和同一份「世界歷史」。

《微光小鎮 Glimmerville》的第三條線。另外兩條是 2D：主線 [GlimmerTown](https://github.com/lijiabao1998/GlimmerTown)，以及美術實驗線 [GlimmerTown-lab](https://github.com/lijiabao1998/GlimmerTown-lab)。

  - 選「路」（五級可選），一指按住拖出一條路，放開才蓋；拖的時候每一格會標出能不能蓋、總價多少。
  - 選「住／商／工」拖出一塊分區；「電」點一下蓋電廠；「拆」一次拆一層；↩ 復原今天的施工，全額退錢。
  - 「公共設施」一組（D016）有十三種：公園、水塔、配水管、消防局、警察局、派出所、醫院、診所、學校、圖書館、郵局、墓園、垃圾場；點一下蓋（公園用框，配水管用拉線）。
  - 按 ▶，城市照實驗線的規則自己長，每天收稅、付維護費；人口到門檻有里程碑獎金，星等升級有獎金。
  - 關掉再開，城還在：目前的城存成實驗線的分享碼，世界歷史一筆一列存在瀏覽器的 IndexedDB（只增不改，D013）。☰ 選單可以匯出分享碼，貼進 2D 實驗線就能開。

- [D019](docs/D019-water.md) 是城市系統的第一張：供水。
  - 「公共設施」一組多了水塔（$400）和配水管（拉線，$10／格）。水塔旁邊接上水管，水管兩格內有電的住商工就有水；一座水塔供 80 棟。二級要有水才升得到三級。
  - 規則照實驗線的舊式供水網逐行搬：實驗線原始碼在 Node 跑 360 張隨機小圖逐格相等；實驗線頁面上 8 個種子拉水管、推進一天，每一棟有沒有水都一樣；讀進來的 AI 城 120 天也一樣（60／314 棟有水）。
  - 水管跟實驗線一樣平常埋在地下，拿著水塔或配水管才畫出來。建築卡講這一棟有沒有電、有沒有水。
  - 人口 500 以上二級升三級還要污水接管，污水還沒搬，所以大一點的城有水也還長不出三級；摩天樓合併也還沒搬。
- [D020](docs/D020-garbage.md) 是城市系統的第二張：垃圾。
  - 「公共設施」一組多了垃圾場（$300，處理 40）。沒有垃圾場、容量不夠、離垃圾場沿路超過 18 格，住宅都會不開心；人口 500 以上只算貼路的處理設施，路網分成清運區，各區自己的容量自己用。城市評分的垃圾那一項也照這個算。
  - 規則照實驗線的清運網與清運區原文搬：實驗線原始碼在 Node 跑 420 張隨機小圖逐格相等；實驗線頁面上 8 個種子蓋垃圾場、推進一天，每一棟住宅的幸福逐位相等（只差糧食那一項）；讀進來的 AI 城 120 天、種子城，把實驗線那一天的輸入代進本線的垃圾那一段，每一棟也逐位相等（種子城本線的人口少算了住宅塔、巨廈，自己推進會不同，列在卡上）。
  - 起步城跟實驗線的差距因此小了一截：第 120 天城市幸福本線 0.234、實驗線 0.236（D019 時本線 0.400）。（這個「幾乎相等」是巧合，D022 查清楚了：見下。）
  - 建築卡多一列「清運」：全城垃圾與容量、垃圾場沿路幾格、有沒有扣分。

- [D022](docs/D022-food.md) 是城市系統的第三張：糧食。
  - 每天算食物量（農場、大農場、牧場、溫室、釣魚碼頭、社區菜園、魚塘；農場看季節）、遊客（觀光建築、地標、會展中心每 20 天一波）、貿易額度（路格、貿易站、港口、貨運、倉儲），居民每 10 人、遊客每 160 人要 1 單位糧食，本地不夠向貿易額度拿；供糧率 −.5 再乘 .11（夾在 −.06～.05）就是每棟住宅每天的幸福加減。起步城沒有農場、額度只有 3，所以人口一多，每棟住宅每天扣約 .045。
  - 規則照實驗線原文搬：實驗線原始碼在 Node 跑 700 張隨機小圖、每張三天，每個計數與數字逐位相等（實驗線原文改 26 處、本線改 38 處，全都轉紅）；實驗線頁面上 80 座城推進一天，判的 75 座、1,323 棟住宅，糧食那一段的每個輸入輸出與每一棟住宅的幸福全部相等；D011、D016、D017、D019、D020 的預建城對拍不再需要「套糧食」，直接相等。
  - 實驗線有、本線沒搬的輸入（物流、化肥、船、火車線、壅堵、城市活動、政策、污水廠）會讓讀進來的城不一樣：AI 城的政策「公園夜間開放」每棟 +.02、種子城進口 4／42，卡上都記了，只量不判。
  - 住宅的建築卡多一列「糧食」。
