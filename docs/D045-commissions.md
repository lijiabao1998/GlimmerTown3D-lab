# D045 市長委託（T385）：搬進本線

**基線**：D044 收工（見 `LOG.md` r44）

**依據**：CLAUDE.md 規則 8（規則跟實驗線對拍）、規則 4（世界歷史只增不改，格式加版本號）、規則 9（資料格式沿用實驗線；本線需要新號先提方案給業主定）。

## 為什麼做這張

- D043 在實驗線頁面上量過：市長委託是一個**零模擬副作用**的小系統——三選一、接單、每天純讀已算好的值累計、完成才一次性 `money += bonus`、過期只發提示。搬進來成本小（一個純函式模組＋一個面板），而且是**玩家有目標可追**的玩法：D043 量到起步城 24 次接單 0 次完成，是因為起步城做不到；有造船廠、鋼材庫存、科技、幸福夠高的城做得到。
- 本線的建造玩法目前只有「蓋東西、看數字長」；委託給中期一個明確的小目標（造船用鋼、期末庫存驗收、研究學術網絡、幸福連續 30 天…），獎金 $1,000–3,200 是一次性的，不改穩態。

## 做什麼

1. **規則**（`src/sim/rules/commission.ts`）：11 條委託表（獎金 1500／2500／1200／2200／1000／2000／1000／2000／1800／3200／3000）、決定性三選一（世界種子＋輪次的雜湊，零亂數）、接單（沙盒、已有進行中的、城市等級 < 3、人口 ≤ 50 都不能接）、放棄（輪次 +1、沒有懲罰）、每天的結算（累計型、連續天數型、科技型、期末驗收型；過期不罰款）、存與讀（欄位 `cms385`，實驗線格式 `{act, st, acc, hold, n, done}`，零狀態不落欄位，畸形整欄棄用回零）。出處與行號寫在檔頭。
2. **接進每天**（`day.ts`）：結算放在實驗線 tick 的最後（收支、晉升、紓困、城市等級都落定之後，56170–56189），純讀當天已算好的值：鋼材用量 `ec.steelUsed`、糧食出口金額 `late.tradeGold`、幸福（取 2 位小數）、鋼材與燃料庫存、科技完成清單；完成才一次性加獎金進資金（不進當天的收入）。`DayReport.commission` 給當天結果。
3. **世界歷史**（城市格式 **10**）：新事件 `cms`（`ev`＝接受／放棄／完成／過期，`id`＝委託，完成帶獎金）；緊湊列 `[24, dDay, 事件碼, 委託碼]`，完成多一欄獎金；沒有座標，是整座城的事。接受、放棄是玩家按的（`edit.ts`），完成、過期是每天結算的結果。重播不改城市的樣子；大事記多一種「接受／放棄委託、委託完成 +$、委託過期」。
4. **介面**（`cityView.ts`、`index.html`）：☰ 多一項「委託」——面板依實驗線的順序顯示：沙盒「沙盒模式無委託」→ 進行中（進度條、獎金、剩餘天數、「🗑 放棄委託」）→ 城市等級不到 3「城市等級 3 解鎖」→ 人口不到 51「人口 50 解鎖」→ 三選一（每張一個「接受」鈕）；底下「紀錄」列已完成的圖示。面板開著、過了一天，進度與三選一跟著換。通知的字與顏色＝實驗線（📋 接受委託／放棄委託〔紅〕／委託完成　+$〔金〕／委託過期〔紅〕）。
5. **公共運量**：本線沒有（公車與票務 D037 沒搬），兩條運量委託（`transit150`、`transit400`）照常出現、可以接（三選一要跟實驗線逐張一致，存檔也要能原樣來回），但面板標明「⚠ 本線還沒有公共運量：這一條做不到、會過期（可以放棄換一批）」；結算時運量給 0，連續天數永遠是 0。

- 不搬完成時的音效與彩帶（`sFanfare`、`spawnConfetti`）、AI 市長自動接單、`mayorObserve483`。
- 不改實驗線的公式與數字（獎金、期限、等級門檻照抄，包括 T394b 的「名字跟值不同」：`transit400` 的名字是「1200×45 天」、`happy80` 是「78%×45 天」，id 不改）。
- 不改任何已對拍的既有公式：沒有進行中委託的城，每天的報告逐欄不變（守衛直接比）。

## 施工中查到的事

- **實驗線的雜湊用浮點、不是 `Math.imul`**：`cmsHash385` 寫成 `(a*374761393+b*668265263+c*2246822519)|0`，種子大的時候乘積超過 2^53，低位被浮點吃掉；本線照原式抄（第一版寫成 `Math.imul`，守衛在大種子上立刻紅），守衛專門有一個把它改成 `Math.imul` 的突變。
- **實驗線的存檔欄位只收整數**：`cmsLoad385` 對 `st`／`acc`／`hold`／`n` 都 `Number.isInteger`；而「造船用鋼」的累計 `acc` 加的是鋼材用量 `steelUsed`（小數）。結果是：**進行中的鋼材委託存檔再讀回來，累計帶小數的話整欄棄用、委託就沒了**（實驗線自己的行為）。本線照抄，守衛釘住（`acc: 12.5` 讀進來回零）。要不要修是業主的事（修了就跟實驗線不一樣，2D 讀本線的碼時行為也不同）。
- **事件的日子**：完成、過期用 `s.day`（`stepDay` 一開始就 `s.day++`，所以結算那一刻的 `s.day` 就是正在結算的那天；D040、D039 的事件在 `s.day++` 之前記、用 `s.day + 1`，兩者指的是同一天）。
- **運量委託**：實驗線的起步城與 M1 底城都沒有公車路線，實驗線的運量一路是 0（100 天劇本到期過期），所以本線給 0 跟實驗線一樣；有公車路線的 2D 城才會不同（D037 量過的缺口）。
- **通知最多留三則**：第一版煙霧在底城上推 1 天，底城一天內從 Lv.6 連升到 Lv.11，三則升級通知把「委託完成」擠掉；改成起步就 Lv.11 的城（`rk: 10`）。這是既有的通知上限，不是這張卡的錯，但提醒：一次事情很多的那天，委託的通知可能被擠掉（大事記與歷史都還在）。
- **既有守衛跟著改**：D043 的「src 沒有委託與政策生命週期的程式」改成「沒有政策生命週期（T504）、委託有（D045）」；D010／D019 寫死「現行格式＝9」的地方改成 10；D011 的 `build.ts` 突變錨點在 D044 時已修。
- **跨讀檔不能比軌跡**：守衛第一版把「存→讀→再推 5 天」跟沒存讀的比，資金不同——讀檔照實驗線用 `seed^day` 重設亂數（規則 8 說過不能跨讀檔比），改成只比委託狀態與一天的結算。

## 沒做成的事（照實講）

1. **運量委託做不到**：兩條公共運量委託（`transit150`、`transit400`）本線永遠完成不了（沒有運量），面板標明、可以放棄換一批；但三選一照實驗線出，所以玩家可能抽到三張裡有兩張做不到。要不要在本線先把它們藏起來、或等公車與票務搬了再說，請業主定。
2. **沒有完成的音效與彩帶**（實驗線 `sFanfare`、`spawnConfetti`）；只有金色通知。
3. **沒有「進行中的委託」常駐提示**：玩家要開 ☰「委託」才看得到進度；HUD 上沒有小圖示。
4. **沒有 AI 市長自動接單**（實驗線的 `mayorObserve483` 沒搬）。
5. **只量了回退設定**：實驗線的預設設定（T504 政策實驗室打開）沒有量委託；D043 說過兩者獨立，沒有證據顯示會互相影響，但沒有實測。
6. **沒有在真的手機上量過**：預算是無頭 Chrome 量的；面板是 DOM、不加 draw call。
7. **等價的邊界**：實驗線頁面實跑用 M1 底城（人口 2,304）、W2（造船廠）與起步城 8 座；沒有量「大城、有真的出口糧食的城」的糧食出口型（`trade1200`／`trade3000` 的累計）完成路徑——這兩條的累計走的是跟鋼材同一段程式（`acc +=` 來源不同），公式層逐項相等，但頁面實跑沒有一座城真的完成過它們。
8. **介面的面板沒有 412×860 的版面檢查**：只驗了 360×740。
