# D005 住商工美術（一）：預設檔、地坪、前庭、窗、屋頂設備

**基線**：`850a963`
**參考**：2D 實驗線 `lijiabao1998/GlimmerTown-lab` @ `d23c18d`（v13.43／T638），只讀。行號都指 `index.html` @ `d23c18d`。

## 為什麼做這張

D004 把住商工的切分與量體照實驗線搬過來了，但近看跟 2D 並排，差距還是一眼看得出來。D004 施工後在四個街區拍了 2D 特寫（住宅區、市中心、工業區、AI 城住宅區），比出四件事：

1. **草坪是 2D 好看的一半原因。** 實驗線 D0 格（切分沒畫的住商工格）畫成草坪，住宅前後有花園、樹、綠籬、圍欄，整座城透氣。3D 的 B 檔把這些格畫成 D003 的灰邊鋪面，像空地。
2. **窗太暗。** 3D 所有牆都用同一張窗磚，窗是深藍黑、再乘牆色。實驗線每個原型有自己的玻璃色與窗型（`pal.glass`，拱窗、厚框、帶狀、店面），辦公樓的帶狀玻璃是亮藍。
3. **平屋頂是一整片素面。** 實驗線平屋頂上有冷氣機、通風管、樓梯間、水塔（`roofKit559` 70588），從上往下看細節最多就在這裡。
4. **地坪與前庭沒東西。** 實驗線的街區地坪依類別上色：住宅深草、商業灰鋪面、工業碎石（`lotFill570` 70790）。前庭放樹、長椅、路燈、停的車、貨櫃、貨車、木箱；villa 有綠籬、圍欄、小徑、花圃（`villaYard559` 70851）。

## 決定

- **預設改成 B（照實驗線）。**
  - 理由：特寫比對下，實驗線好看的來源正是 B 的樣子，空格是草坪、不是洞。C 把 D0 全補成建築，工業區從 2D 的十幾棟變成六十棟，比實驗線擠很多。
  - A、C 和 D003 現況都留著切換：`?blocks=a|c|off`，面板四顆鈕。
  - 實驗線哪天定了 D0 要不要畫（它的 T633 §1），本線照對拍跟上。
- **一律照實驗線的畫法翻成 3D**，數字能搬的照搬。
  - 屋頂設備的件數公式照搬，並且對拍。
  - 位置、大小是 3D 的近似，照實記。
  - 實驗線的亂數（`metroRand516`）不搬，改用本線的決定性雜湊。這是渲染細節，不影響切分與量體的對拍。

## 做什麼

1. **預設檔**：不帶 `blocks` 就是 B；`?blocks=off` 是 D003 現況。
2. **地坪**（地面貼圖，每格一色系）：
   - 街區蓋到的格，依 k 上色，照 `lotFill570`：住宅 `#6f8a58`、商業 `#87888c`、工業 `#6d675d`，另加兩色雜點。
   - 蓋到 villa 的格用 `#54833f`（`villaYard559`）。
   - D0 與被吸收的格：跟一般草地同一套草色（它們在實驗線就是草坪）。
3. **前庭道具**（依 `lotFill570`／`villaYard559` 的件數與種類）：
   - 位置落在主體框外的空地，優先前庭（v 大的一側）。
   - 住宅：樹 ≤3、長椅 ≤4、路燈 ≤2。
   - 商業：停的車 ≤4（七成有車）、花台 ≤3、路燈 ≤4。
   - 工業：貨櫃 ≤3、貨車 ≤2、木箱 ≤3。
   - villa：後兩邊綠籬、前兩邊矮圍欄、三棵樹、一塊花圃、車道與車。
   - 樹沿用城市場景的樹網格（多一批實例，不多 draw call）。
4. **窗**：
   - 牆面窗磚依原型的 `win` 換樣式：arch、punch、grid、ribbon、shop；玻璃用配方調色盤的 `glass`。
   - 商業核心路徑的一樓是店面帶：高 min(11, 牆高×0.36) px，玻璃 `#8ec4e0`（71409）。
   - 工業牆下半不開窗（71396 `skipI`）。
   - 做法：一張窗磚圖集＋每個頂點記樣式與玻璃色，著色器依樣式取格。
   - 第 0 格跟 D003 的窗磚逐像素相同，300 年示範與 `?blocks=off` 的畫面不變。
5. **屋頂設備**：
   - 平屋頂（平頂原型、商業小街區、工業 ≥4 格、上層量體頂、第二量體頂）照 `roofKit559`。
   - 件數＝clamp(round(area×0.9), 2, 9)，area 照各呼叫點的式子（71339、71373、71379、71427、71430、70787）。
   - 種類依 k 輪換：冷氣機、通風管、樓梯間、水塔。
6. **沿街小件**：
   - 商業核心路徑的正面雨遮：數量 clamp(長邊, 2, 8)，顏色輪換 accent 系（71322）。
   - 住宅核心路徑一戶一扇門（`bayDoor557`）。
   - 工業正面裝卸口（71384）。

**施工中自己抓到、照實記下的事**

1. **第一版超出預算三倍。** 點綴全部放進投影子的網格，種子城 A 240,732（3.04 倍）、C 142,236。三角形數含影子那一趟，所以每件點綴都算兩次。依序改了六件，A 降到 115,994：

   - 小煙囪不投影子；
   - 街區模式的野樹樹幹不帶上下蓋：下蓋朝地、上蓋藏在樹冠裡，畫面逐像素相同，D003 模式照舊；

   - 店面帶與工業牆腳帶原本各多一圈牆（8 個三角形，影子再 8 個），改由著色器依高度換窗型（`windows.ts` 的 `wBand`），不多幾何。
2. **實驗線的店面窗畫在牆頂。** `isShop` 的條件是 `row ≥ h − shopH − 1`，`row` 從牆腳往上數，所以大窗其實在最上面那列；壓暗的店面色帶與雨遮卻在牆腳（71322、71409）。3D 把店面窗放在牆腳，跟色帶、雨遮一致。
3. **實驗線小商業街區的屋頂設備大多被蓋掉。** 設備先畫、女兒牆頂板後畫（71373）。3D 放在頂板上，看得見。件數照公式，對拍不受影響。
4. **更正 D004 的一條「沒做成」：2D／3D 取景並沒有偏。**
   - 實驗線的 `lookAt` 對準格子北角，3D 對準格心，只差半格。
   - 縮放換算 3.42 在水平、垂直都對。
   - 看起來偏，是因為畫面中央的大型貨櫃碼頭（36,35）在 2D 有吊車，在 3D 還是灰色佔位箱。
5. **對照圖中間那格「D004 的 B」是真的 D004。** 把 `850a963` 在 scratch 的暫時 worktree 建置一份，拍完就移除 worktree，建置結果留在 `scratch/d004-dist/`（不進版本庫）。
