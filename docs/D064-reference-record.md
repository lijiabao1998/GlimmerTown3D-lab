# D064 參照紀錄

十四個形都是**原創、依遊戲腳印縮尺的程序外觀研究**，不是量測掃描，也不是任何一處的復刻；程式不載入任何照片或圖像素材（規則 7）。每個形對一個真實的英國高層或大型住商建築，只取它登錄文字裡寫明的外觀輪廓（平面、量體劃分、頂部構件），再依 2×2 或 3×3 的腳印與預算自由改編；改編的部分寫在「我的改編」欄，不當成真實特徵。**配色不取自這些建築**（名單多半沒給顏色，給的也與遊戲的類別色衝突），用種類的實驗線色，見卡面驗收 3。

  1. Historic England 官方頁對自動抓取回 **HTTP 403**（研究代理與我都試過），所以清單文字**全部取自 [British Listed Buildings](https://britishlistedbuildings.co.uk/) 鏡像**（頁面的 Source ID 就是 NHLE 編號；網址規則 `https://britishlistedbuildings.co.uk/10<編號>`）；沒有第二個獨立來源核對鏡像文字的保真度（Heritage Gateway 轉址後同樣被擋）。

  3. 沒有看任何參照照片、沒有量任何實際高度；層數與年代全部是名單自己寫的。**把真實層數對應成遊戲的 8.07／7.39／4.32／7.76 或 5.65／6.56／9.15 等格高，是設計選擇，不是名單事實**（種類表的高度早就定了，我只是把形配到變體上）。
  4. 多棟或整個屋邨的條目只取了與外觀有關的部分：Barbican 條目正文很長，我只取三座塔（33）；Byker 在 NHLE 是多個條目，我只讀了 1392166；Alexandra Road 的鏡像正文開頭夾著幾條 "See under" 的交叉參照。
  5. 33、34 沒有「真正矮」的候選以外的選擇：34 的四個都是 24 層以上，4.32 格的矮型用 The Rotunda（圓柱、24 層、腳印比例短）；interwar 的高塔太少，只有 Senate House 夠高。
  6. 各案例的實地現況（是否仍存在、是否開放、外觀是否另有改動）沒有查；只用名單條文。The Rotunda 的外牆馬賽克在 2005–08 年改建時換成玻璃，現狀與原貌不同。Leeds 沒有搜尋；Dawson's Heights 不在 NHLE（開放資料名稱搜尋與範圍搜尋都沒有）；Gorbals、Red Road 在蘇格蘭，不在 NHLE 範圍。
