# D000 願景：同一座城、三種時間

**日期**：2026-09-24
**決定者**：業主（三種玩法都做、公開、放 `C:\dev`）
**整理**：Claude
**來源**：業主與 GPT 的討論（業主貼進對話），以及 Claude 讀 2D 實驗線草稿時的觀察。

## 為什麼要開這條線

2D 的 GlimmerTown 已經佔住了「我造一個世界」這個位置。業主不想做換皮，而光是把它搬進 3D，核心動作還是「建造、看城市長大」，本質上就是換皮。

所以這條線的前提是：**3D 不是賣點，玩家做的事才是。**同一個世界要提供三種完全不同的核心動作。

## 三種玩法

| 玩法 | 玩家做什麼 | 視覺承諾 |
|---|---|---|
| **建造**（3D 版 GlimmerTown） | 鋪路、劃區、供電，創造條件讓城市自己長 | 第 1 天一條路，第 100 天一座城 |
| **一生** | 陪一個市民從出生到老去。城市由 AI 市長代蓋；玩家只在人生轉折點做決定：搬不搬家、換不換工作、留下還是離開 | 拉近是他的日常（上班的路、他家窗戶的燈），拉遠是他一輩子看著長大的城市 |
| **考古** | 城市荒廢數百年後走進廢墟，從建築、改建痕跡、道路改道、墓園、帳冊裡推理這座城的歷史。遊戲不給標準答案 | 廢墟裡看得出好幾個年代疊在一起 |

三種玩法其實是**同一座城的三個時間點**：你親手蓋出它 → 有人在裡面活完一生 → 它變成廢墟，被人重新讀懂。

## 地基：世界記得自己的歷史

三種玩法全部依賴同一件事：

- 每一棟建築何時蓋、何時升級、何時被拆、原地又蓋了什麼；
- 每一條路何時鋪、何時改道；
- 每一個市民何時搬進搬出、在哪工作、何時離世。

這些都記成**只增不改的事件**。
- 建造模式用它來呈現「看得出歷史的城市」：老城核心還在，外圍長出密集街廓，而不是新城把舊城蓋掉。
- 一生模式用它當那個人的背景。
- 考古模式用它生成廢墟和線索，而且線索是真的模擬出來的，不是寫死的劇本。

**這是整個倉庫最先要蓋好的東西。**

## 設計原則（來自業主與 GPT 的討論）

- **每 5–10 分鐘，世界都要肉眼看得出變化。**
- **開局和終局並排，不用說明就看得出玩家創造了什麼。**所有功能都為這張並排圖服務（D001 先做它）。
- **縮放本身就是玩法**：近景看生活，中景看街區，遠景看城市結構，超遠景看區域交通網。
- **小而密**：地圖有邊界（64×64 或 96×96），讓玩家最後看見整張地圖被自己的決策填滿，像一盆盆景。
- **成功帶來複雜度**：擁堵、垃圾、犯罪是因為城市長大才出現，不是懲罰玩家。
- **存檔就是玩家的履歷。**
- **核心循環不爽，就不准加新系統**：先修美術、互動回饋、成長節奏。

## 畫風（待 D001 對照圖後由業主決定）

Claude 推薦的是**像素風 3D**：用真正的 3D 模型，低解析度渲染、最近鄰放大，加上描邊和有限的調色盤，並保持「光從左邊來」。好處有三：
- 延續 2D 版的身分，遠看仍是像素城市，卻可以自由旋轉、有真實的陰影和日夜；
- 低解析度渲染本身就替手機省效能；
- 兩條 2D 線的美術規矩（「先有燈具才有光」「變體要結構差異，不是換色」）可以直接沿用。

D001 會同時拍出兩三種畫風的對照，由業主挑（CLAUDE.md 規則 1）。

## 技術方向

| 項目 | 方向 |
|---|---|
| 渲染 | three.js（WebGL2；WebGPU 留作後路） |
| 程式碼 | TypeScript 分模組；建置時輸出**單一 HTML**，離線可用、可以放上 Pages |
| 模擬 | 純邏輯模組，不碰 DOM，可以在 Node 裡無頭測試；固定種子 |
| 介面 | DOM 疊加在畫面上（中文字不在 3D 裡畫） |
| 驗收 | 無頭 Chrome 煙霧測試＋ GitHub Actions；手機可玩版本走 Pages |

**可以從 2D 線帶過來的資產**（要先驗證，不是既定事實）：2D 實驗線的建築草稿，繪圖工具庫本身就是用 3D 座標描述建築的。`boxZ(u, v, 寬, 深, 高度, 高)` 是量體，`gableU／gableV／hipU` 是屋頂，`faceL／faceR` 是牆面，最後才投影成像素。只要寫一個「3D 版工具庫」，同樣的版面函式就有機會直接長出 3D 建築。限制有兩個：直接畫螢幕像素的部分（小人、點綴、光線步進）要改成貼圖或看板；各批草稿的工具庫不盡相同，要先盤點。

## 里程碑

1. **D001 視覺承諾**：同一座城在「開拓那年／一生盡頭／數百年後的廢墟」的三聯圖，加上畫風對照；同時搭好工具鏈（Vite＋TS＋three、單檔輸出、煙霧測試、Actions、Pages）。
2. **世界歷史的資料結構**，加上決定性的模擬骨架。
3. **3D 觀景**：匯入 2D 版的分享碼，把玩家現有的城市用 3D 呈現。
4. 三種玩法各做一個能玩的最小原型：**建造**（路、區、電、成長）、**一生**（跟隨一個市民，AI 市長代蓋）、**考古**（快轉到衰亡、廢墟、線索）。

每一個里程碑都要能玩或能看；不追求一開始就跟 2D 版功能齊全。
