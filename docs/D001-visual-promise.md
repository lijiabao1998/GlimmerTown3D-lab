# D001 視覺承諾：同一座城的三個時間＋畫風對照＋工具鏈

**基線**：`9e235bc`（D000 開線）

## 為什麼先做這張

照 D000，所有功能都要為「開局和終局並排」那張圖服務。本線有三種玩法，所以承諾是**三聯圖**：同一座城在「開拓那年（第 0 年）／一生盡頭（第 80 年）／數百年後的廢墟（第 300 年）」。

畫風還沒定，照 CLAUDE.md 規則 1，同一組三聯圖用三種畫風各拍一次，交給業主挑。

## 改什麼

1. **工具鏈**：Vite、TypeScript、three.js；建置時輸出單一 `dist/index.html`（`vite-plugin-singlefile`），離線可用。
2. **世界歷史骨架**（`src/sim/`，純邏輯，不碰 DOM 與 three）：
   - 固定種子亂數（mulberry32）；
   - 在 48×48 的有界地圖上，逐年生成**只增不改的事件**：鋪路、蓋建築、升級、拆除重建、廢棄、倒塌、植物蔓生；
   - 任一年份的城市狀態＝把事件從頭套用到該年份，**不另外存快照**；
   - 年份 0→80 是城市成長（城中心、河、路網外擴、住商工分區、地標），80→300 是衰亡；
   - 早期蓋的建築保留它那個年代的樣式（尖頂紅磚），晚期的換成平頂、玻璃，好讓「看得出城市的歷史」。
3. **渲染**（`src/render/`）：只讀某一年的城市狀態，建出 three.js 場景，不回頭改模擬。三種畫風是同一條渲染管線的三組參數：
   - **A 像素風 3D**：三分之一解析度渲染、最近鄰放大、深度描邊、三階色塊受光、硬陰影；
   - **B 平滑低面數**：全解析度、平滑受光、柔和陰影；
   - **C 卡通描邊**：全解析度、三階色塊受光、深度描邊。
   - 三種都保持「光從左邊來」，鏡頭都是斜 45° 正交，接近 2D 版的視角。
4. **觀看頁**：可切換年份與畫風，手機可旋轉縮放。
5. **拍照工具與煙霧測試**：無頭 Chrome 開建置後的單檔頁面，拍 3 畫風 × 3 年份，共九張。

## 不改什麼

- 不做任何可玩的建造、UI 面板或存檔。這張只證明「樣子」和「歷史能驅動畫面」。
- 不碰兩條 2D 線。

## 驗收（動手前寫）

1. `npm run build` 產出單一 `dist/index.html`，不依賴任何外部網路資源。
2. `npm run typecheck` 零錯誤。
3. **決定性**：同一種子生成的事件雜湊，兩次載入必須相同；換種子必須不同。
4. **歷史只增不改**：第 300 年的事件列表，前段必須逐筆等於第 80 年的事件列表。
5. **三個年份肉眼看得出差別**：建築數量與平均高度，第 80 年都大於第 0 年；第 300 年的「完好建築」比例低於第 80 年，植被多於第 80 年。以數字斷言，不靠肉眼。
6. **煙霧測試**：無頭 Chrome 載入，WebGL 可用、畫面非空白（取樣像素的變異量大於門檻）、console 零錯誤。
7. 九張樣張拼成對照圖交給業主，由業主挑畫風。

## 施工紀錄

- **工具鏈**：three 0.186、Vite 8、TypeScript 7、vite-plugin-singlefile。`npm install` 回報零漏洞。建置出單一 `dist/index.html`，582 KB（gzip 149 KB），three.js 包在裡面，不需要網路。
- **模擬層**（`src/sim/`）：import 寫明 `.ts` 副檔名，Node 24 可以不經建置直接跑，模擬測試不必靠瀏覽器。種子 5162026 生成 6,916 個事件，約 45 毫秒。
- **兩次自己抓到的問題**：
  1. 第一版第 80 年幾乎沒有高樓（四樓以上只有 13 棟）：「老城保護」半徑 7 太大，市中心長不高。縮到半徑 4、外圈商業放寬到 6 樓後，四樓以上有 80 棟。城市變成「低矮紅磚老城被一圈高樓環繞」，看得出歷史。
  2. 第一版第 300 年有 62% 的建築倒成瓦礫，遠看被樹蓋住，讀不出廢墟。衰敗放慢之後，198 棟是站著的空殼、115 棟倒塌，地標衰敗更慢，鐘樓留作廢墟裡的地標。
- **假數字修正**：煙霧測試原本印出「1 次呼叫、2 個三角形」，量到的是後製四邊形，因為 three.js 每畫一次就會把統計歸零。改成在城市那一趟之後記下數字，真值是 **9 次呼叫、50,942 個三角形**。
- **守衛有效性**：把畫布清成全黑，「畫面非空白」檢查的變異量會變成 0，判紅燈。
- **煙霧測試綠燈**（23 秒）：
  - WebGL2 可用；
  - 決定性（雜湊 `1750cc89`），換種子不同；
  - 只增不改：只生成到第 80 年的結果，等於 300 年版的前 80 年；
  - 建築 5→379、平均樓層 1→2.49、完好比例 100%→5%、樹 405→1,032、430 條路長草；
  - 3 畫風 × 3 年份畫面都非空白；
  - console 零錯誤。
- **樣張**：`docs/img/D001-compare-near.png`（近景，對焦老城核心）、`docs/img/D001-compare-full.png`（全景）。由上到下是 A／B／C，由左到右是第 0／80／300 年。
- **沒做成**：
  ① 廢墟的空殼太完整，只是變矮、沒屋頂、長青苔，還沒有參差的斷牆和破洞；
  ② 河岸是按格子切的階梯狀，平滑畫風 B 下特別明顯；
  ③ 高樓只有一種盒子樣式，還不夠多樣（D000 說要搬 2D 草稿的工具庫，這張沒碰）；
  ④ 還沒在實機手機上量過幀率，只有無頭 SwiftShader；
  ⑤ 畫風尚未定案，等業主看圖挑。
