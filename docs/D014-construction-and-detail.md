## 做什麼

### 1. 樓體照屋齡長出來（著色器裁切，不必每天重建）

- 每一格一筆「施工資料」：屋齡、這一格建築幾何的最高點、地基高度、分類與區（mood），存成一張 N×N 的浮點貼圖。每天更新一次，重建場景時更新最高點。
- 牆、其他、點綴三種材質都加同一段裁切：片段所屬的格＝頂點位置往建築內收、夾進自己那棟（或那個街區）的地界。
  - `t = 屋齡 + 當天已經過的比例`（播放中才有小數，暫停時是整數）。
  - `t < 3` 全部藏起來；`3 ≤ t < 9` 只畫到 `地基 + rise(t) × (最高點 − 地基)`；`t ≥ 9` 全畫。
  - `rise` 在 t＝4…8 的整數天**逐項等於實驗線的 riseF**（.30、.50、.68、.84、.96），t＝3 是 0、t＝9 是 1，中間線性。1 倍速下每一幀都在長高，不是一天跳一級。
- 影子那趟（深度材質）用同一段裁切：沒蓋的部分不投影子。
- 街區是一整塊合併的幾何：同一街區裡，已完工的鄰格被新格切開的那一面，補一片「工地圍網」擋住切口（施工層畫，跟著兩邊的高度走）。
- 前庭的樹等完工（t ≥ 8.6）才種下去。

### 2. 工地一個網格、頂點動畫

- 每棟屋齡 < 9 的建築（公園除外）一座工地，蓋在它自己的地界上。分期照上表；物件的形狀、配色照實驗線的色碼，3D 的擺法本線自己定（規則 1 補充）。
- 所有工地合成**一個網格、一個 draw call**（投影子）。每個物件帶「出現、消失的 t」，出現時從地面長出來、消失時縮回去。
- 挖掘機擺臂、塔吊旋轉、吊鉤跟著樓板高度上下、攪拌車滾筒轉、焊接火花、發電機閃燈、揚塵、工人走動，都在頂點著色器裡算，每一幀只改兩個 uniform。
- 樓板線、鋼筋頭、樓板上的工人、鷹架跟著當下露出的高度走。
- **動畫只在播放時跑**：暫停時畫面靜止，維持「靜止 0 幀」（D002 起的守衛）。實驗線的 `visT` 暫停時也在走，這一點刻意不同。
- 工地網格每天重建一次（只有工地，很小）。場景重建規則改成：**屋齡 ≥ 2 的工地，場景裡一定已經有它的幾何**（原本最多等 5 天）。所以 t＝3 開始長高時，樓體一定在。

### 3. 地面只重畫變動的格

- 重建時比較每一格的輸入（路、等級、鐵路、碼頭、電車、地形、高地、分區、建築分類、地坪、非住商工地坪、四鄰有沒有路），一樣的格直接沿用上一次的像素。
- 結果要跟整張重畫**逐位元組相同**。

### 4. 屋齡風化（T591／T606）

- 住商工核心路徑的牆（英美立面不疊，照實驗線），屋齡 ≥ 14 起有雨漬、接地苔垢、簷下積灰。分級、強度、密度、長度、透明度、顏色、區（mood）照上面的實驗線公式。
- 位置是 3D 的：每 8px（受光面，本線 +z 面）／11px（側面，+x 面）一格，換成世界單位。畫在著色器裡，屋齡每天變、分級跟著變，不必重建。
- 整層乘 `detailAlpha432`：把相機換算成實驗線的縮放（一格的水平寬度 ÷ 64px）。

### 5. 近看小物（T599／T606）
