## 為什麼做這張

D010 之後城市會自己長，但玩家什麼都不能做。這張做出第一個能玩的循環：
- 開一座新城，手上 $3000；
- 鋪路、劃住商工、蓋電廠和警察局、拆除，每一樣都花錢；
- 按 ▶，城市照 D010 的規則長，每天收稅、付維護費；
- 錢、電、人口一眼看得到；關掉再開，城還在。

規則、數字照實驗線，跟實驗線對拍（規則 8）；按鈕和手勢本線自己設計（業主：UI 可以更現代）。

## 做什麼

### 1. 資料：照實驗線的格式與編號（規則 9）

- **編號**：建築種類 k、分區 1／2／3、道路等級 1–5、地形碼都照實驗線。這張用到的都是現成編號（1–3 住商工、5 發電廠、11 警察局），不新增。
- **存檔格式**：實驗線的分享碼格式，跟 D003 讀、D010 產生起步城碼的是同一種。
- **附加欄位**：本線的世界歷史放在附加欄位 `d3`，實驗線原有的欄位一個都不改。實驗線有先例：擴充版分享碼的 `egoal`（64902 起）。
- **兩邊互通**：3D 蓋的城匯出分享碼，貼進實驗線能開；實驗線匯出的碼，本線讀得回。

### 2. 開局

- **新城**（這張的主角）
  - 種子城的地形（地形、高地、樹），其他清空。
  - 標準難度 `df:1`、資金 $3000：實驗線預設難度的起始資金，`DIFF_MONEY[1]`（39435），也是 `newWorld` 給的數（51110）。
  - 第 1 天、種子 5162026、星等 0、里程碑 0。
  - 碼由 `node tools/lab-extract.mjs --part=d011` 產生，實驗線讀回的對帳數字要跟本線相同（同 D010）。
- **起步城**
  - D010 那一座，碼不動（`df:3` 沙盒）。
  - 照實驗線的沙盒規則：蓋東西不花錢（51505），不做每日結算（56053）。
- **我的城**：有存檔時排在最前面，接著上次繼續。
- **其他城**：種子城、AI 城、全種類照舊只能看。

### 3. 工具：規則照實驗線

放置照 `doPlace`（51626 起），判斷能不能蓋照 `canPlace`（51262 起），造價照 `placeCost`（51504 起）。

- **加價與拒絕**：樹上蓋東西加 $2（51623）。造價大於資金就拒絕，剛好相等可以蓋（51631）。
- **副作用照實驗線**：放置前先標地價髒框（51627）、覆蓋與污染蓋印、砍樹時的污染減免（52397），以及警察局抽的那一次亂數。
- **為什麼要有警察局**：住宅升二級需要警察覆蓋（55645）。三級要學校、供水、污染低於 15（55646、55648），這張不做，所以城市最高長到二級。

### 4. 手勢：語意照實驗線觸控（T436），介面本線自己做

- **路**
  - 按下後拖到終點，路線是先 x 後 y 的 L 形（`roadDraftTiles436` 62597）。
  - 放開手指才蓋，從起點一格一格蓋；錢中途不夠時，蓋前段、略過後段（`commitRoadDraft436` 62779）。
- **分區、拆除**
  - 拖出矩形。放開時先算總價，不夠就整塊不蓋；夠就從左上角逐列蓋（`commitRect` 62974、62996）。
  - 矩形拆除會略過二級以上的住商工；單格拆二級以上的建築要再按一次確認（62983）。
- **電廠、警察局**：點一下就蓋。
- **預覽**：拖曳時顯示每一格能不能蓋，以及總價；錢不夠時總價變紅。
- **鏡頭**
  - 選了工具：一指建造，兩指縮放、平移。實驗線的兩指不能平移（62866），本線加上。
  - 沒選工具：照舊一指旋轉。
- **滑鼠**：用同一套語意（預覽、放開才蓋）。實驗線的滑鼠是按下就蓋、自由描，本線不照搬。
- **復原 ↩**
  - 同一天之內，可以一筆一筆往回退：還原格子、全額退錢、重算覆蓋，亂數不倒回。照 T460（66570、66597）。
  - 過了一天就不能退。實驗線可以隔好幾天再退，連帶刪掉之後長出來的建築，本線不照搬。
  - 不做重做。

### 5. 資金：照實驗線每天結算（56053）

- **每天結算**
  - 稅收逐棟算，照每天建築清單的順序：住 55962、商 55963、工 55965。
  - 減掉維護費：路照 `ROAD_UPKEEP`（37429），每座電廠 4、每間警察局 4（55969–55990）。
- **結算之後依序**
  - 人口里程碑（`MILES` 37861，56081）；
  - 星等獎金（56100–56131）；
  - 紓困 $250：資金 < 20、當天淨額 ≤ 0、距上次紓困 60 天以上（56142）。
- **第 2 類系統的乘數先固定**
  - 實驗線照跑、本線沒搬的有：經濟快照、貿易進口、城市活動、夜間城市。
  - 這張把它們的乘數固定為 1、進口費為 0。
  - 差距照 D010 的做法量出來、記在卡上。
- **這張不做**：貸款、稅率調整；服務預算固定 1。
- **負債**：不會輸，只是造價大於資金時不能蓋（照實驗線）。

### 6. 世界歷史（規則 4）

- **每一格的變動記一筆事件**，只增不改，陣列順序就是真相。`g` 是同一筆手勢的編號：
  - `{day, t:'road', x, z, rc, cost, g}`
  - `{day, t:'zone', x, z, zone, cost, g}`
  - `{day, t:'place', x, z, k, lv, v, id, cost, g}`
  - `{day, t:'doze', x, z, layer, k?, id?, cost, g}`
  - `{day, t:'undo', g}`
- **拆掉的建築留墓碑**：保留編號，記拆除日。
- **格式**：`CITY_FORMAT` 2 → 3，格式 1、2 照讀。重播跟模擬用同一個套用函式。
- **卡片**：建築卡、空地卡列出這一格的事件（第幾天鋪路、劃區、蓋、拆）。

### 7. 存檔

- **什麼時候存**：自動存到 localStorage，時機是每一筆手勢之後、播放中每 5 天、離開頁面時。

### 施工中遇到、照實記下

- **工作流被用量上限打斷**：第一次三路代理做到一半停下，留下半成品的 `build.ts`、`money.ts`。重跑時要它們逐行重審半成品；建造那一路回報沒有邏輯要改，只補了註解與行號；資金那一路重寫、沿用既有的名稱和形狀。
- **拆多格建築的造價記錯**：點附屬格拆整棟時，事件造價記成 0（錢照扣）。整合守衛的「扣款＝事件造價」抓到，改成記在第一個碰到它的格。
- **沒蓋成卻沒有理由**：同類重劃（實驗線 51664 回傳 false 但沒有理由字串）、降級被拒時，介面不知道要說什麼。改成從預覽推出理由（「已經是這一區」「已為同級或更高級道路」）。
- **煙霧測試的觸控**：
  - `Input.synthesizeTapGesture` 受實際視窗大小限制，手機版下方的按鈕會回報座標超界，改用 `dispatchTouchEvent` 按下＋放開。
  - 同一個分頁連續換頁很多次之後，Chrome 的觸控模擬不再把觸控事件送進頁面（`elementFromPoint` 是畫布，頁面卻收不到任何 pointer／touch 事件；單獨重現不出來）。煙霧 D011 段改成三個 Chrome 各跑一段。根本原因沒追到。
  - 清掉存檔後直接換頁，舊頁面離開時 `visibilitychange` 又把城存回去；改成先到只能看的樣本城清存檔。
- **播放鈕只有 40 px**：`index.html` 裡 300 年示範的 `#play { width: 40px }` 用 ID 選擇器蓋掉了建造介面的 44 px，加更具體的選擇器。
- **對照圖差一天**：實驗線拍照那一跑的天數標籤、本線參考跑的天數各錯一天（「第 N 天」到底是推進 N 次還是 `day`＝N），都改成 D010 的算法（推進 N 次之後），並加上「瀏覽器重演的雜湊＝Node」核對。
- **合成圖下方重複一截**：截圖視窗比內容高、或比無頭 Chrome 的螢幕寬時，下方會再畫一次上面的內容。改成把視窗設成內容大小再拍，介面前後那張改成兩欄。
