# D008 英美立面逐戶造型與飾條

**基線**：`8999376`
**參考**：2D 實驗線 `lijiabao1998/GlimmerTown-lab` @ `d23c18d`（v13.43／T638），只讀。行號都指 `index.html` @ `d23c18d`。
**授權**：業主 2026-09-25「全部做完吧」；美術由 Claude 判斷（CLAUDE.md 規則 1 補充）。

## 為什麼做這張

D004 把住商工裡走「英美立面」的原型只畫成外形：一個量體加坪頂或斜頂。D005 補了核心路徑的點綴。但實驗線的立面繪製器（T577，72936–74660）逐戶畫了很多東西，現在 3D 裡都還看不出來：

- **連棟屋（ukTerrace）**：石板長脊、每戶一樓凸窗、分戶牆上的煙囪。
- **半獨立屋（ukSemi）**：兩戶鏡像一對、四坡陶瓦頂、兩層凸窗、門廊雨遮。
- **維多利亞排屋（ukVictorian）**：灰泥、女兒牆、簷口、一樓陽台帶。
- **大宅（ukMansion）**：紅磚、白石樓板帶、孟莎屋頂加天窗。
- **高街（ukHighStreet）**：一樓店面、板岩屋頂、轉角角樓；二級是旅館（孟莎屋頂、雨遮、名牌）。
- **布朗石（usBrownstone）**：門前石階、托架簷口。
- **戰前公寓（usPrewar）**：石基座、簷口、屋頂水塔、防火梯。
- **主街（usMainStreet）**：階梯式女兒牆、雨遮、招牌。

核心路徑的飾條（`classicTrim565`／`modernTrim565`，70700 起）也沒搬：
- 石或磚基座、腰線、簷口、轉角石；
- 現代風的女兒牆與門廳。

## 做什麼

1. **飾條的選法照實驗線，對拍。**
   - 抽取加記 `__t547.sty`（核心路徑的 `sty565`＝(v＋k＋寬) mod 3）。
   - 1,728 組跟配方逐項相等。
   - 飾條種類照 71460 起的分支：
     - villa、工業不畫；
     - 原型名含 modern 用現代，含 town／stone 用石；
     - 其餘 sty 1 用石；sty 2 時商業用現代、其他用磚。
2. **逐戶造型**：`src/content/facades.ts`（純函式）算每個立面街區的戶數、每戶的寬度與高低起伏，以及凸窗、煙囪、門、石階、角樓、水塔的擺放；`src/render/blockArt.ts` 依計畫畫。
   - 戶寬取實驗線的量級：連棟屋約半格一戶，半獨立屋一格一對。
   - 顏色：磚、灰泥、石板、陶瓦、布朗石用固定的幾組色（實驗線立面繪製器自帶色，不走調色盤），逐戶用雜湊輪換。
3. **飾條**：核心路徑的建築依上面的選法加基座帶、腰線、簷口、轉角石，或現代的女兒牆與門廳帶。
4. **只在 B、C 兩檔加**：
   - A 檔（一格一棟、密度對照）維持 D007 的樣子。理由：種子城 A 檔離手機預算上限只剩 156 個三角形，而 A 檔有幾百棟 1×1 的立面小屋。
   - 預設是 B。

## 不改什麼

- 切分、量體、屋頂設備、前庭、窗型都不動（對拍的黃金樣本照舊）。
- 非住商工、地面、明暗、300 年示範不動。
- A 檔不動。
- 夜景不做；立面上的招牌字、門牌不做。

## 驗收（動手前寫）

1. **對拍**：
   - 1,728 組的 `sty565` 跟配方相等；
   - 注入「sty 改用 (v＋k) mod 3」要紅。
2. **逐戶計畫**（Node 跑 1,728 組）：
   - 每個立面街區的戶數 ≥1；
   - 每戶都在主體框裡、戶與戶不重疊、加起來剛好蓋滿正面；
   - 凸窗、石階等都貼在正面、不出地界；
   - 同一組配方擺法固定。
3. **畫出來＝計畫**：瀏覽器裡，B、C 兩檔兩城，畫出的戶數、凸窗、煙囪、石階、角樓、水塔、飾條件數都跟計畫相同。
4. **A 檔不變**：A 檔兩城的三角形與 draw call 跟 D007 定稿相同（種子城 118,728、AI 城 78,324）。
5. **手機預算**：B、C 兩城 ≤ D003 基線 1.5 倍、draw call ≤ 18。
6. **點擊**：點立面上的凸窗、石階，回到那個街區的建築。
7. **對照圖**：
   - 立面多的兩個特寫（種子城住宅區、市中心），實驗線 2D｜D007｜D008；
   - 手機直式。
8. **上線**：Node 守衛、煙霧、Actions、Pages 綠。
