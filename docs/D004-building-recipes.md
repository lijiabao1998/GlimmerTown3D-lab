# D004 建築配方與街廓密度（住商工）

**基線**：`35313d4`
**參考**：2D 實驗線 `lijiabao1998/GlimmerTown-lab` @ `d23c18d`（v13.43／T638），只讀。下文行號都指 `index.html` @ `d23c18d`。
**對拍**：依 CLAUDE.md 規則 8。這張搬的是公式層，所以要**逐項相等**。

## 為什麼做這張

D003 把實驗線的城市原樣搬進 3D，但住商工只是量體佔位：每格一棟，高度量自精靈圖。跟 2D 並排，有兩個落差一眼看得出來：

1. **密度**：實驗線把相鄰的同類住商工併成超街區，一塊地畫一張大圖；3D 每格一棟，所以市中心比 2D 密。
2. **外形**：實驗線住商工的外形由原型表 `ARCHE568` 決定，包括佔地框、高度倍率、第二量體、平頂或坡頂；3D 只有四種通用盒子。

這兩件都是規則 1 說的「全局觀感」，所以這張不替業主選：三檔都做好，拍同一個畫面的對照圖。**預設畫面維持 D003 現況**，等業主挑定才改。

## 從實驗線讀到的事（原樣照搬，怪癖也照搬）

### 超街區切分

- **誰能併**（`rciMergeable547` 70454）：住商工（k 1–3）裡同一個 k 的建築，等級不必相同。例外是第一級住宅的 villa 原型，它不併（T602，`arNameVilla600` 70747）。
- **起點**（`rciBlockOrigin547` 70457）：左鄰、上鄰都不是可併的同類。
- **認領**（T633，`buildPart633` 70493）：依掃描序（y 先、x 後）。後到的街區不准伸進已被認領的格子。
- **長法**（`rciGrow633` 70477）：
  1. 先長正方形，上限 4（T602 `blockMax602` 70456）。
  2. 再往右長、再往下長，兩個方向上限都是 4。
  3. 截斷：
     - T603 聯排：住宅第一級進深 1，第二級以上進深 2；商業第一級進深 2。進深取短邊，看的是**起點那格**的等級。
     - T604：工業最大 2×2。
- **等級與變體**：`rciGrow633` 回傳的是區內最高等級與那格的變體（`maxLv`、`v`）。但繪製時拿的是**起點那格**的等級與變體（61581）。本線照抄這個怪癖。
- **截掉的格子**：沒有人畫。它們上鄰是同類，所以不是起點；也沒被任何街區認領。實驗線叫這類格子 D0「看不見的建築」，業主還沒挑檔（實驗線 T633 卡 §1）。
- **T555 吸收**（`rciAbsorbed555` 71878）：一個 1×1 起點，上下左右只要有同類鄰居屬於 ≥4 格的街區，就不畫。

### 量體（`makeBlockSprite547` 71253）

- **原型**：取 `ARCHE568[k_lv][|v| mod 表長]`（70657、70742）。
- **牆高**（像素，span＝短邊）：
  - lv1＝14＋3·span；lv2＝20＋4·span；lv3＝26＋5·span。
  - 再乘原型的 hm、四捨五入，至少 8（T601）。
- **坡高**（p＝屋脊方向的邊長）：
  - lv1＝14＋4·p；lv2＝18＋5·p；lv3＝22＋6·p。
  - 住宅改成 max(12, 8＋3·span)，商業固定 8。
  - 屋脊方向（`ridgeAxis554` 70536）：長邊比短邊多 2 以上就順長邊，否則看 v 的奇偶。
- **上層量體高**（stepH）：lv1＝10，lv2＝16，lv3＝22。
- **佔地框** `box`＝[u0,u1,v0,v1]：u 沿地圖 x，v 沿地圖 y（`paraPt559` 70584）。地圖 y 在 3D 裡對到 z。
- **T582 前後分棟**：原型沒有第二量體、街區 ≥6 格（工業 ≥4 格）、進深框 ≥0.5 時，沿進深切成前後兩棟：
  - 中間留 0.08 的巷；
  - 後棟高度 ×0.85。
- **T602 裙樓**：第二量體是整塊地、而且街區 ≥4 格時：
  - 裙樓改成 [.08,.92,.06,.38]；
  - 高度倍率不超過 0.40。
- **第二量體高**＝max(6, round(牆高 × ex.hm))。
- **屋頂分支**：
  - **立面路徑**：原型帶 `fs`，就交給英美立面繪製器（T577）。例外是 T604「一戶一尖」：進深 ≥2 的非平頂住宅不走立面。立面繪製器自己回報是不是坡頂。
  - **核心路徑**（其餘）：
    - 平頂原型：平頂。
    - 住宅：一戶一個山牆，戶數＝clamp(長邊, 2, 8)。
    - 商業：平頂加 4px 女兒牆。
    - 工業：<4 格是鋸齒屋頂，齒高照 `sawRise608` 70931；≥4 格是平頂。
- **上層量體**：核心路徑上 ≥4 格的非住宅，屋頂中央再疊一個上層量體。四邊各內縮 32%（`shrinkPara547` 70526），高 stepH。
- **顏色**：`metroPalette516(k, v, 1, lv)`（70268），再經 `speciesPal601`（70748）與 `shade`（39978）。
- **像素換成格**：跟 D003 一樣除以 39.2（D003 卡「高度換算的理由」）。

## 三檔（業主挑）

| 檔 | 名稱 | 住商工怎麼分塊 | 看起來 |
|---|---|---|---|
| A | 一格一棟 | 每格自己一塊，用 1×1 配方 | 最密 |
| B | 照實驗線 | 切分、吸收、D0 空格全照實驗線 | 最像 2D，街廓裡會有草坪空格 |
| C | 超街區補滿 | 先照實驗線切。還沒被認領的格子（D0）當成新起點，依掃描序用同一套長法補切；被吸收的 1×1 照畫 | 塊狀跟 B 相同，但沒有空格 |

- 三檔的住商工用同一套配方；非住商工不動，照 D003。
- 網址 `?blocks=a|b|c` 切換，面板上也有切換鈕。
- 不帶參數就是 D003 現況。

## 不改什麼

- 城市模型、解碼器、世界歷史格式都不動。切分與配方只讀城市、不改城市（規則 2）。
- 非住商工的 170 多種建築、道路、地面、樹都不動。
- 立面細節不搬：英美立面的逐戶高度、窗、店面、招牌都不搬。窗型只記在配方裡，這張不畫。
- 夜景、施工中（T635）、廢棄外觀都不做。T622 旋轉對調也不做，3D 用不到。
- 不碰任何 2D 倉庫。

## 驗收（動手前寫）

1. **原型表**：`lab-arche.json` 跟實驗線執行期的 `ARCHE568` 深度相等。
2. **切分對拍**：兩座樣本城逐格比對實驗線的 `rciBlockOrigin547`＋`rciAbsorbed555`，差異 0。
   - 比的是：是不是起點；寬、高、k、lv、v；是否被吸收。
   - Node 跑一次，瀏覽器跑一次。
   - 另外列出統計：
     - 街區數、多格街區數；
     - 住商工格分四類的格數：畫在多格街區、單格、被吸收、D0 沒人畫；
     - 重疊格數，必須是 0。
3. **量體對拍**：1,728 組逐項比對實驗線，差異 0。比的是：
   - 原型名、路徑、坡頂旗標；
   - 牆高；
   - 主體框四個分數（位元相等）；
   - 第二量體的框與高度；
   - 調色盤七個顏色字串。
4. **守衛有效**：注入以下錯誤，每一種都要讓對應守衛變紅：
   - 聯排進深 1→2；
   - 拿掉「villa 不併」；
   - 拿掉掃描序認領；
   - T582 門檻 6→5；
   - T602 裙樓上限 0.40→0.45；
   - 繪製改用街區的 maxLv。
5. **三檔都畫得出來**（瀏覽器，兩座城）：
   - **A**：每一棟建築都畫到，同 D003 守衛。
   - **B**：
     - 畫出來的住商工格，跟實驗線畫的格相同；
     - D0 格數、被吸收格數，跟黃金樣本相同。
   - **C**：每一格住商工剛好屬於一個畫出來的街區，沒有空格，也沒有重疊。
   - 三檔的非住商工都要全數畫到。
6. **點得到**：每檔、每座城各抽 20 個多格街區，點街區中心。要回到該街區裡的建築，建築卡要打得開。
7. **預設不變**：不帶 `blocks` 參數時：
   - 三角形數、draw call、畫到的建築數，都跟 D003 基線相同。基線在本輪動工前量過：種子城 79,256 個三角形、12 次 draw call；AI 城 70,910 個、12 次。
   - D003 的守衛照舊全綠。
8. **手機預算**：
   - 三檔在兩座城的三角形數，都不超過 D003 基線的 1.5 倍；
   - draw call 不超過 18；
   - 建場時間照實記進卡面。
9. **純度與素材**：
   - `src/content/*.ts` 不 import three，也不碰 DOM；
   - 零外部請求照舊。
10. **對照圖**：
    - 三個視角，每個五格：實驗線 2D、D003 現況、A、B、C。視角是種子城中景、種子城遠景、AI 城中景。
    - 另拍一張手機直式。
