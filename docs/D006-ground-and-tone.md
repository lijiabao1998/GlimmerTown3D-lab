# D006 全城色調、草地、道路

**基線**：`f9e5add`
**參考**：2D 實驗線 `lijiabao1998/GlimmerTown-lab` @ `d23c18d`（v13.43／T638），只讀。
**授權**：業主 2026-09-25「全部做完吧」，D005 沒做成的事接著做；美術由 Claude 判斷（CLAUDE.md 規則 1 補充）。

## 為什麼做這張

D005 做完後跟 2D 並排，差最多的是整片地面與整體明暗：

1. **草色偏暗偏黃。**
   - 3D 的草是 `#78a452`～`#6c9749` 的雜色；
   - 實驗線的草是 `#74b258` 一族（D004 抽取拍的 2D 圖逐色統計：遠景 24.8% 的像素就是 `#74b258`），每一格還有一條淡淡的亮邊（`#82c467`、`#82b357`），讀起來像一塊塊草皮。
2. **道路是淺褐灰。**
   - 3D 的路面是 `#6b6a66`，邊 `#8a8780`；
   - 實驗線的柏油是深藍灰（`#4e525b` 一族），有人行道、車道線。
3. **水、沙也都差一點。**
   - 實驗線近景的水是 `#3f7ec0`／`#407fc1`，沙是 `#d9c689`。
4. **立面明暗對比弱。**
   - 實驗線是「左亮右暗」：受光面用 `pal.light`、背光面用 `pal.dark`（T541），兩面差很多，例如住宅 `#e7c6a2` 對 `#77443c`。
   - 3D 背光面只比受光面暗兩成左右，整座城讀起來灰灰平平。

## 做什麼

1. **地面貼圖解析度**：每格像素從 4 提到 8（地圖 ≤128 格時；貼圖邊長上限 1,024），才畫得出草皮格線、人行道、車道線。
2. **地面色**（顏色取自上面的逐色統計）：
   - 草：`#74b258` 一族，每格左、上兩邊一條亮邊 `#82c467`；分區底色照舊淡淡疊上。
   - 水：`#3f7ec0` 一族，亮點照舊。
   - 沙：`#d9c689` 一族。
   - D005 的地坪（住宅、商業、工業、villa）與 D0 草坪照舊，草坪改用新草色。
3. **道路**：
   - 柏油 `#4e525b` 一族；
   - 靠非道路的一側畫 1 像素人行道 `#c6c0ac`；
   - 直路中線：一般路白色虛線，幹道（`rclass ≥ 4`）黃色實線；
   - 橋：柏油加淺色護欄；高速公路照舊黃邊。
4. **立面明暗**（只改 2D 城市模式，300 年示範不動）：做三檔，拍同一個畫面對照後挑一檔。
   - 甲：現況。
   - 乙：背光面壓暗。三階色塊的中間階從 175 降到 120，天光從 1.1 降到 0.9。
   - 丙：乙，再把受光面提亮。太陽 2.2 升到 2.6。
5. **對照圖**：實驗線 2D、D005、甲乙丙，同一個畫面；另拍中景、遠景、特寫、手機直式。

## 不改什麼

- 建築的幾何、配方、點綴、切分、對拍都不動（三角形數、draw call 逐位不變）。
- 300 年示範不動（它有自己的地面貼圖與材質）。
- 樹的形狀、地形高低不動。

## 驗收（動手前寫）

1. **地面色逐格驗**（瀏覽器讀地面貼圖）：
   - 草格的像素都在草色族或格線色裡；
   - 水、沙、柏油也都在各自的色族裡。
2. **道路**：
   - 每一格路，面向非道路的那一側邊上全是人行道色；
   - 直路（只有對向兩鄰是路）的中線上有車道線；
   - 路口不畫車道線。
3. **幾何不變**：三檔兩城、`?blocks=off` 的三角形與 draw call 跟 D005 相同；300 年示範的雜湊、三角形、draw call 不變。
4. **明暗**：挑定的那一檔寫進卡面，附對照圖與理由。
5. **手機**：地面貼圖邊長 ≤1,024。
6. **上線**：Node 守衛、煙霧、Actions、Pages 綠。
