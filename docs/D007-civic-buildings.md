# D007 非住商工建築造型

**基線**：`8d67043`
**參考**：2D 實驗線 `lijiabao1998/GlimmerTown-lab` @ `d23c18d`（v13.43／T638），只讀。
**授權**：業主 2026-09-25「全部做完吧」；美術由 Claude 判斷（CLAUDE.md 規則 1 補充）。

## 為什麼做這張

- 住商工以外的 182 種建築，從 D003 起都是量體佔位。高度量自實驗線精靈圖，外形只有四種通用盒子，顏色依分類猜。
- 貨櫃碼頭在 2D 有紅色吊車和貨櫃堆，在 3D 是灰箱；市政中心在 2D 有圓頂，在 3D 也是灰箱。
- 這是 D005、D006 之後跟 2D 最大的落差。

## 做什麼

1. **顏色取自實驗線**：抽取加 `--part=d007`，逐種讀實驗線的精靈圖（`SPR.bld`），每一級 v0 各讀一份，存成 `src/content/lab-looks.json`。每種記五個色：
   - **地坪**：佔地菱形前半、沒被建築蓋到的像素，取最常見的色；
   - **屋頂**：每一欄最上面 30% 的不透明像素；
   - **受光牆**：錨點左邊、屋頂以下；
   - **背光牆**：錨點右邊、屋頂以下；
   - **點綴色**：飽和度高的最常見色。

   都排除描邊的深色。
2. **全種類樣張城**：`src/content/gallery.ts` 把 182 種各擺一棟（lv1、v0），擺在一片草地上，照分類排好。
   - 用種子城的存檔當樣板、清掉逐格圖層，編成分享碼。
   - 實驗線自己匯入讀回，對帳數字存起來，跟 D003 的樣本同一套作法。
   - 3D 多一個樣本「全種類」；實驗線拍同一片的 2D 圖，逐種對照。
3. **造型**：`src/content/kindShapes.ts`（純函式）是每一種的造型表：類型加參數。`src/render/kindArt.ts` 依表畫。
   - 類型約二十種：高樓、市政（柱廊、圓頂）、學校、醫院、車站、港口（吊車、貨櫃）、機場、電廠（煙囪、冷卻塔）、水壩、太陽能、風力、變電所、儲槽、公園、球場、遊樂設施、農場、垃圾場、消防治安、商業特種。
   - 地標性的（鐘樓、燈塔、電視塔、凱旋門、摩天輪、風車、雷達、天文台、火箭……）另給專屬造型。
   - 高度照 D003 量到的實驗線高度；顏色用上面的五色。
4. **用地地坪**：非住商工建築的格子改用該種的「地坪」色（D006 之前是一律淺灰鋪面）。
5. **範圍**：只在街區模式（預設 B、A、C）換造型；`?blocks=off` 仍是 D003 現況。

## 不改什麼

- 住商工、道路、地面色、明暗、300 年示範都不動。
- 城市模型、解碼器、世界歷史格式不動。
- 夜景、施工中、廢墟外觀不做。

## 驗收（動手前寫）

1. **顏色**：有精靈的每一種都有五色，出處記實驗線 commit；單元守衛驗格式與涵蓋率。
2. **樣張城**：
   - 182 種各一棟，沒有重疊、沒有出界；
   - 實驗線匯入後量到的對帳數字跟本線解碼逐項相等。
3. **造型表涵蓋**：182 種都有造型；沒有落到「預設盒子」的。單元守衛逐種驗。
4. **不出界**：每棟建築所有三角形都在自己的佔地內，外挑不超過 0.1 格。瀏覽器逐棟驗，樣張城與兩座樣本城都驗。
5. **高度**：模型最高點跟實驗線量到的高度比。
   - 實驗線高 ≥0.35 格的，要在 0.7～1.3 倍之間；
   - 貼地的（<0.35），模型不高過 0.45 格；
   - 例外逐種寫明理由（例如電視塔的天線）。
6. **顏色用上**：每棟模型的頂點色裡有該種的受光牆色與屋頂色（實驗線有的話）。
7. **地坪**：非住商工建築的格子像素都在該種的地坪色族裡。
8. **點擊**：樣張城每一棟從正上方點中心，都回到那一棟。
9. **手機預算**：三檔兩城與樣張城，三角形 ≤ D003 基線 1.5 倍，draw call ≤ 18。
10. **不變的**：`?blocks=off` 的三角形與 draw call 跟 D003 基線相同；300 年示範不變。
11. **對照圖**：
    - 樣張城逐區 2D｜3D；
    - 種子城中景、AI 城中景；
    - 手機直式。
12. **上線**：Node 守衛、煙霧、Actions、Pages 綠。
