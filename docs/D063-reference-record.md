# D063 參照紀錄

十一組模型都是**原創、依遊戲街區縮尺的程序外觀研究**，不是量測掃描，也不是任何一處的復刻；程式不載入任何照片或圖像素材（規則 7）。每組對一個真實的英國商業或辦公建築，只取它登錄文字裡寫明的外觀輪廓，再依街區的縮尺與預算自由改編；改編的部分寫在「名單未載／我的改編」欄，不當成真實特徵。
